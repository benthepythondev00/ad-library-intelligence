# Ad Library Intelligence

Competitor ads from the Meta, Google Ads Transparency and LinkedIn ad libraries, plus ads.txt sellers.

Use the tools of the `Ad Library Intelligence` MCP server when the user asks for this data. Ask for a small `limit` first and widen it only when asked. If a call answers 401, the MCPize API key is missing or expired: tell the user to run `gemini extensions config` for this extension.
